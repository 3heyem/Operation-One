# Operation One

Operation One ESP script built with the prodordie UI framework.

## Features
- Live ESP for traps, charges, utility, and cameras with distance scaling
- Off-screen arrows for tracking targets outside your view
- FOV changer with aim detection
- Categorized multi-select filters
- Built-in config saving and theme options

## Usage
```luau
loadstring(game:HttpGet("https://raw.githubusercontent.com/3heyem/Operation-One/refs/heads/main/Operation%20One"))()
```
Press F5 to open the UI (this can be changed in the Settings tab).
